# ICE drop box

Upload any ICE file here exactly as you downloaded it. The file name does not matter: each file is recognised by what is inside it.

**Daily files (download each business day)**

- Settlement reports for cotton, coffee, sugar No 11 and cocoa: the options report and the small futures report (PDF)
- Coffee "C" certified warehouse stock report (`coffee_cert_stock_YYYYMMDD.xls`)
- Cocoa certified stock report (`cocoa_cert_stock_YYYYMMDD.xls`)
- Cotton certificated stock by delivery point

**Weekly files (Mondays)**

- Cotton certificated stock: grade and staple, by warehouse, year of growth, strength, four months and older (CSV)

**Monthly files (after the last business day of the month)**

- Coffee certified stock aging report (`coffee_aging_YYYYMMDD.xls`)
- Coffee end-of-month certified stocks by port (`EOM_KC_cert_stox_by_port...xls`; the whole history is in each copy)
- Coffee grading summary analysis (PDF)
- Cocoa grading results with discounts (`Cocoa_Grading_Results_with_Discounts_EOM_....xls`)

**Once a year (when ICE publishes a new list)**

- Coffee "C" licensed warehouses list and the storage and handling rates (PDF)

A .zip of any of these works too.

How: **Add file → Upload files**, drop the files, then **Commit changes**.

Each file is read, recognised and added to its history within a few minutes, and this folder empties again. Uploading the same report twice is safe: the newer copy replaces that day's (or month's) figures.
Check the **Data status** tab on the desk to see what was received.

A file that is not recognised is moved to `unrecognised/` and listed on the Data status tab. You can delete it from there once it has been looked at.
