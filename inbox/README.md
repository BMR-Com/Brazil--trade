# ICE drop box

Upload any ICE file here exactly as you downloaded it. The file name does not matter.

- Settlement reports (options and futures daily market reports) for cotton, coffee, sugar No 11 and cocoa
- Cotton certificated stock reports (by delivery point, grade/staple, by warehouse, year of growth, strength)
- The coffee "C" certified warehouse stock report
- A .zip of any of these

How: **Add file → Upload files**, drop the files, then **Commit changes**.

Each file is read, recognised and filed within a few minutes, and this folder empties again.
Check the **Data status** tab on the desk to see what was received.

A file that is not recognised is moved to `unrecognised/` and listed on the Data status tab. You can delete it from there once it has been looked at.
